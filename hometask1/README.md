# Домашнее задание 1

Запуск

Нужен Python 3, дополнительные библиотеки не нужны. 

python3 dfvs_v_3.py < input.gr > output.txt

Программа читает граф из стандартного ввода и выводит номера удаляемых вершин по одному в строке. 

Идея алгоритма

Сначала упрощаем граф: убираем вершины без входящих или исходящих дуг, не добавляя их в ответ. 
Если у вершины только одна входящая или исходящая дуга, убираем её и соединяем каждого её предшественника 
с каждым её последователем напрямую. Если появилась петля, добавляем её вершину в ответ. 
Когда упрощать больше нельзя, добавляем в ответ вершину с наибольшим произведением числа входящих и исходящих дуги. 
Повторяем упрощения пока не останется доступных вершын.

Затем один раз проходим по найденному ответу и пробуем вернуть каждую вершину в граф. 
Алгоритмом Кана проверяем, остались ли циклы если циклов нет, возвращённую вершину исключаем из ответа.
