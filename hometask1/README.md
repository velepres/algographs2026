# Домашнее задание 1 — Directed Feedback Vertex Set

Запуск

Нужен Python 3, дополнительные библиотеки не нужны. 

python3 dfvs_v_3.py < input.gr > output.txt

Программа читает граф из стандартного ввода и выводит номера удаляемых вершин по одному в строке. Время работы и размер ответа выводятся отдельно, в stderr.

Идея алгоритма

Сначала упрощаем граф: убираем вершины без входящих или исходящих дуг, не добавляя их в ответ. 
Если у вершины только одна входящая или исходящая дуга, убираем её и соединяем каждого её предшественника с каждым её последователем напрямую. Если появилась петля, добавляем её вершину в ответ. 
Когда упрощать больше нельзя, добавляем в ответ вершину с наибольшим произведением числа входящих и исходящих дуг, удаляем её и повторяем упрощения.

Затем один раз проходим по найденному ответу и пробуем вернуть каждую вершину в граф. Алгоритмом Кана проверяем, остались ли циклы: последовательно убираем вершины без входящих дуг; если удалось убрать все оставшиеся вершины, циклов нет и возвращённую вершину исключаем из ответа. Иначе оставляем её в ответе. Общий лимит поиска — 60 секунд. Если время закончилось или пришёл SIGTERM, завершаем текущий шаг и прекращаем поиск; если жадный этап не завершён, добавляем в ответ все оставшиеся вершины рабочего графа. Минимальность ответа не гарантируется.

## Часть 2

hard.gr — граф из 100002 вершин и 600390 дуг, без петель и повторяющихся дуг.
hard.ans — корректный ответ: вершины 19342 и 54082. После их удаления циклов нет.
