# Домашнее задание 1 — Directed Feedback Vertex Set

## Запуск

Нужен Python 3, дополнительные библиотеки не нужны. Из папки `hometask1`:

```sh
python3 dfvs_v_3.py < input.gr > output.txt
```

Программа читает граф из стандартного ввода и выводит номера удаляемых вершин по одному в строке. Время работы и размер ответа выводятся отдельно, в stderr.

## Идея алгоритма

Нужно удалить как можно меньше вершин, чтобы в графе не осталось направленных циклов. Сначала упрощаем граф: убираем вершины без входящих или исходящих дуг, не добавляя их в ответ. Если у вершины только одна входящая или исходящая дуга, убираем её и соединяем каждого её предшественника с каждым её последователем напрямую. Если появилась петля, добавляем её вершину в ответ. Когда упрощать больше нельзя, добавляем в ответ вершину с наибольшим произведением числа входящих и исходящих дуг, удаляем её и повторяем упрощения.

После этого пробуем по одной вернуть вершины из ответа. Если после возврата циклов нет, оставляем вершину в графе. Проверяем это алгоритмом Кана: последовательно убираем вершины без входящих дуг; если удалось убрать все, циклов нет. На поиск отводится 60 секунд. При истечении времени или получении SIGTERM прекращаем поиск; если упрощение ещё не завершено, добавляем все оставшиеся вершины в ответ. Алгоритм ищет небольшой корректный ответ, но не гарантирует минимальный.

## Часть 2

- `hard.gr` — граф из 100002 вершин и 600390 дуг, без петель и повторяющихся дуг.
- `hard.ans` — корректный ответ: вершины 19342 и 54082. После их удаления циклов нет.
